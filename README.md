# 📚 Book Store Analysis

## 📌 Project Overview

**Book Store Analysis** is a SQL-based data analytics project focused on analyzing book sales, customer purchasing behavior, inventory, revenue, and genre performance.

The project uses relational data from **Books, Customers, and Orders** tables to answer business questions and generate meaningful insights using SQL.

The goal of this project is to demonstrate practical SQL and data analysis skills by transforming raw bookstore data into useful business insights.

## 🗃️ Dataset

The project uses three main datasets:

### 📖 Books

Contains information about books available in the bookstore, including:

* Book ID
* Title
* Author
* Genre
* Published Year
* Price
* Stock

### 👥 Customers

Contains customer information such as:

* Customer ID
* Name
* Email
* Phone
* City
* Country

### 🛒 Orders

Contains transaction-level information including:

* Order ID
* Customer ID
* Book ID
* Order Date
* Quantity
* Total Amount

## 🔍 SQL Analysis

The project includes SQL queries to analyze different aspects of the bookstore business.

### 📊 Sales Analysis

* Calculate total revenue
* Calculate total number of orders
* Calculate total books sold
* Calculate average order value
* Identify best-selling books
* Analyze sales by genre
* Analyze sales by author

### 👥 Customer Analysis

* Identify customers with multiple orders
* Analyze customer purchasing behavior
* Find high-spending customers
* Analyze customer purchase frequency
* Identify the most frequently purchased genre for each customer

### 📚 Book & Inventory Analysis

* Identify books with low stock
* Find best-selling books
* Analyze book prices
* Analyze books by genre
* Identify books with high sales and low remaining stock

### 📈 Business KPI Analysis

The project also combines major business KPIs into a single result:

* **Total Revenue**
* **Total Orders**
* **Total Books Sold**
* **Total Customers**
* **Average Order Value**
* **Best-Selling Book**
* **Best-Performing Genre**
